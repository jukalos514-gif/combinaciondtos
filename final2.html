El Documento Maestro

Es el esqueleto del documento. Contiene la información corporativa estática: textos legales, encabezados institucionales, firmas del remitente y logotipos. Es el molde invariable que recibirá los datos dinámicos.

Estructura Fija Base

El Origen de Datos

Es la matriz o base de datos estructurada. Por lo general, se trata de una hoja de cálculo de Microsoft Excel donde la fila superior contiene los títulos de las columnas (encabezados de variables) y las filas inferiores representan cada registro único.
